# Notifier

Telegram-бот для напоминаний о задачах.

Июль – август 2025

---

Помогает двигаться к большой цели маленькими шагами. Можно настроить тон напоминаний (от мягкой поддержки до жёсткой дисциплины) и частоту уведомлений.

Приложение на Node.js и Telegraf с PostgreSQL. Упаковано в Docker и деплоится через docker-compose. Можно вести через Portainer/Stacks.

# Стек

- Node.js
- Telegraf
- PostgreSQL
- Docker / docker-compose
- GitHub Actions
