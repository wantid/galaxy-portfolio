# Last Shift

Turn-based 2D multiplayer game built as a Telegram bot.

February – March 2025

---

Made with limited resources using only mobile development tools (Termux, ACode) and a remote server for the database.

## Features

- Turn-based gameplay
- Multiplayer via Telegram
- Visibility area
- Interactive objects and tools
- Lobby system
- Procedural level generation

# Stack

- Node.js + Express
- Telegraf (Telegram Bot API)
- PostgreSQL
- Docker
- Jimp
- dungeon-generator
